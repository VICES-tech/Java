# 🎮 Démineur (Minesweeper) — Java

Implémentation du jeu classique du Démineur en Java, réalisée dans le cadre de ma formation BUT Informatique (BUT1), en console.

## 📋 Description

Ce projet consiste à reproduire les règles du Démineur : une grille contenant des mines cachées, où le joueur doit révéler des cases sans tomber sur une mine, en s'aidant des indices numériques (nombre de mines adjacentes) pour déduire leur emplacement.
